# DailyPlate · 智能日常饮食管理助手

> 拍照记录每一餐，热量与营养一目了然。
> 
> 2026年南京大学智能软件工程小组作业

DailyPlate 是一款面向个人用户的饮食记录与管理工具。用户拍下每餐照片即可完成记录，系统识别食物并估算热量与营养成分；结合身高、体重、年龄、活动量等个人信息估算基础代谢与每日能量需求，并根据减脂、增肌、维持等目标持续给出饮食建议、保留记录并生成定期总结。

> 项目状态：早期开发中。

---

## 功能特性

### 核心能力

- 拍照记录：上传每餐照片，识别食物种类与份量，估算热量及宏量营养素（蛋白质 / 碳水 / 脂肪）。
- 个人档案：录入身高、体重、年龄、性别、活动水平等信息，用于个性化计算。
- 代谢估算：基于个人档案估算 BMR（基础代谢率）与 TDEE（每日总能量消耗）。
- 目标管理：支持减脂、增肌、维持体重等目标，并据此计算每日推荐摄入区间。
- 个性化建议：结合当日摄入、目标与营养结构，给出可执行的饮食调整建议。
- 记录与回顾：按餐次 / 日 / 周记录摄入情况，定期生成总结报告。
